Consumer Shopping Preference Prediction

Overview
This project uses machine learning to predict how customers prefer to shop, whether online or in-store. The analysis is based on customer behavior, spending patterns, and demographic information.

Dataset
The dataset is taken from Kaggle:
https://www.kaggle.com/datasets/minahilfatima12328/consumer-shopping-trends-analysis

Research Questions
1.	How accurately can machine learning models predict a customer’s shopping preference?
2.	Which model performs the best for this dataset?
3.	What impact does data preprocessing have on model performance?
4.	Which features have the greatest influence on a customer’s shopping preference?
5.	How reliable and practical is the final model for real-world use?

Project Structure
The repository is organized into three main parts:
notebooks contains all Jupyter notebooks for each research question
results tables contains all generated CSV tables
results figures contains all generated PDF figures

How to Run
Open Kaggle
Upload the notebooks
Attach the dataset
Run all cells

Requirements
pandas
numpy
matplotlib
scikit-learn
